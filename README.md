## 🛒 Rota de Compra

Faça suas compras de forma mais rápida e inteligente.

Monte sua lista de compras e siga a rota mais eficiente dentro do mercado.<br>
O sistema organiza os produtos, indica em quais corredores eles estão e guia você pelo caminho ideal.

- 🎯 Menos tempo procurando.
- 🎯 Menos caminho percorrido.
- 🎯 Mais praticidade para suas compras.<br>
